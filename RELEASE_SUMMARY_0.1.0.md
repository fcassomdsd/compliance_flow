# Release 0.1.0 - Public Summary

Node-RED Compliance Inspection API `0.1.0` is the first structured pre-production release.

## Highlights
- Added inspection report and inspection plan workflows.
- Added Alfresco integration flows for report/plan and canonical import.
- Added reference endpoints for inspectors, inspections, assignment groups, specialties, and locations.
- Added findings and follow-up flows, including follow-up sequencing.
- Added risk level support in checklist items and non-conformities.
- Improved checklist export by adding item codes for clearer Alfresco records.
- Fixed normativa cardinality handling to return a single object per protocol question.
- Added project governance docs: README, LICENSE (Apache-2.0), and NOTICE.

## Release Status
- Pre-production release (not deployed to production).

## Tag/Release Description (short copy)
Initial pre-production release of the Node-RED Compliance Inspection API. Includes inspection plan/report workflows, Alfresco integration, findings and follow-up flows, expanded lookup endpoints, and checklist data quality improvements.
